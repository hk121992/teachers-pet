# Teacher's Pet — Project Plan

## Milestone 1: MVP (COMPLETE)

Full-stack teaching assistant with AI-powered paper marking and report generation.

### Tasks (all done)
- [x] FastAPI backend with SQLAlchemy ORM (5 models, 6 routers)
- [x] React frontend with TypeScript (8 pages)
- [x] Classroom and student management (CRUD)
- [x] Assessment tracking by subject
- [x] Parent conversation logging (phone, email, in-person, WhatsApp)
- [x] AI paper marking via Claude Vision (image + PDF)
- [x] AI report generation (term reports, meeting prep)
- [x] Student performance charts (Recharts)
